# Public Prompt Specifications

This directory publishes portable prompt contracts that can be reviewed without private infrastructure or research state.

Current entry:

- [`web/ONE_PASTE_T1_T9_COORDINATOR_PROMPT.md`](web/ONE_PASTE_T1_T9_COORDINATOR_PROMPT.md): give a problem-repository URL and ask a coordinator to return exactly nine self-contained T1–T9 Candidate-research prompts.

The prompt is not a worker launcher, repository admission, verifier, or mathematical-result authority. Its source version may precede validation/release of any internal Suite or Web Harness; version equality must never be inferred.
