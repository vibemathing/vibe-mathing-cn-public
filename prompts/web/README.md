# Web GPT Prompt

`ONE_PASTE_T1_T9_COORDINATOR_PROMPT.md` is the public zero-barrier coordinator prompt specification.

It intentionally keeps the first-response contract simple: one repository URL in, exactly nine T1–T9 code blocks out. It does not expose or bypass a controlled repository's separate pre-admission process. In repositories that carry a strict `WEB_COORDINATOR.md`, that contract remains authoritative for runnable, identity-bound worker prompts.

High-assurance clauses are planning constraints, not claims that a verifier ran. Trusted challenge separation, typed identity, independent semantic faithfulness, toolchain freshness and sandbox-external replay remain distinct gates. Missing or unqualified routes stay `blocked/undetermined`.

[`publication-manifest.v1.json`](publication-manifest.v1.json) binds the public prompt digest and records the current source/validation/release state without exposing a private repository identity or revision.
