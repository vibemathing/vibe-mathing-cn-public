# Public Prompt Assets

`prompts/` contains public, portable prompt specifications only. These files are derived publication artifacts, not mathematical truth, verifier receipts, runtime authorization, or evidence.

- Do not add non-public repository identities or source revisions, host paths, sessions, credentials, endpoints, runtime logs, research artifacts, or unpublished receipts.
- A prompt may create Candidate planning instructions only. It cannot authorize GitHub writes, local workers, verifier capabilities, Evidence, Result, or Solution.
- Keep PLFB as the sole conceptual metamodel root.
- Publication changes require an explicit file allowlist, privacy/license/freshness review, and the public repository checks before merge or push.
